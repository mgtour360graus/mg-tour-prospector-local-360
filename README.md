# Prospector MG Tour 360 — ambiente de testes

Aplicação estática preparada para GitHub Pages. Os dados ficam no `localStorage` do próprio navegador.

## Proteções desta versão

- não possui credenciais;
- não se conecta ao WhatsApp;
- não usa Evolution API;
- não envia mensagens;
- não sincroniza dados pessoais com o GitHub;
- exige auditoria, consentimento e aprovação antes de liberar a simulação.

Os cinco registros iniciais são fictícios. Use **Configurações → Restaurar dados de demonstração** para reiniciar os testes.
